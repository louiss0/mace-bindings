# mace_dart

Official Dart bindings for Mace.

## Status

This package provides a Dart-native API around the `mace` CLI. Supported
release binaries are included in the package and selected automatically for the
current platform. Pass `macePath` when a project needs a different Mace
executable.

## Development

This package is managed with the Dart SDK.

```bash
dart pub get -C packages/dart
dart analyze packages/dart
dart test
```

## Usage

```dart
import 'package:mace_dart/mace_dart.dart';

final value = await json('./config.mace');
final inlineValue = await transform('{ name: "Mace", }');
final runtimeValue = await json('./runtime.mace', input: '{ env: "prod", }');
final outputRecord = await output('./config.mace');
```

## API

- `json(path, { input?, macePath?, cwd? })` → `Future<MaceRecord>`
- `transform(source, { input?, macePath?, cwd? })` → `Future<MaceRecord>`
- `jsonText(path, { input?, macePath?, cwd? })` → `Future<MaceRecord>`
- `output(path, { macePath?, cwd? })` → `Future<MaceRecord>`
- `importJson(input, { macePath?, cwd? })` → `Future<MaceRecord>`
- `importYaml(input, { macePath?, cwd? })` → `Future<MaceRecord>`
- `importToml(input, { macePath?, cwd? })` → `Future<MaceRecord>`
- `importFile(path, { macePath?, cwd? })` → `Future<MaceRecord>`

`macePath` is optional; the package uses its bundled platform binary when it is
not provided.

## Records and errors

`transform` writes Mace source to a temporary file, evaluates it through the
CLI, and deserializes its JSON result into a `MaceRecord`. `jsonText` is
retained as an alias for `json`; `output` evaluates the supplied Mace file;
and `import*` evaluates the Mace source generated by the CLI import command. A
`MaceRecord` contains strings, numbers, booleans, nested records, and lists.

CLI failures throw a `MaceError`. Alongside `message` and `exitCode`, its
`diagnostic` provides a best-effort structured view of the CLI stderr:
`category`, `code`, `message`, `range.start.line`, `range.start.column`, and
`path`. The current CLI text protocol does not always provide every field, so
`category`, `code`, `range`, and `path` are optional.
